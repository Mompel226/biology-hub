# Biology Hub — the front door

The map a student lands on. It does one job: show the four shelves and let them pick one.

    Biology Hub
      ├── Foundations      the science every other topic leans on   (2, 3, 4, 5)
      ├── The human body   ← built, live                            (7, 9–16)
      ├── Plants                                                    (6, 8, plant reproduction)
      └── Life on Earth                                             (1, 17, 18, 19)

Not built yet, and deliberately not published — a placeholder front door is worse than no
front door, because students would find it. The repository exists so the name is reserved
and the folder, the repo and the future URL already agree.

**Planned URL:** `https://mompel226.github.io/biology-hub/`

## What it needs to do

- Four shelves, each opening its own map.
- A **course path** cutting across them — "Year 9 · Autumn" — for whatever is being taught
  now. Shelves say where an idea belongs; a path says what the class is doing this week.
- The shared glossary, searchable from here.
- Progress across every lab, in one place.
- An IB toggle. IB is a layer on the existing labs (`further` notes, `ext` and `sup`
  badges), not a fifth shelf.
